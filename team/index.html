Team & Reps

Roster from reps.json, performance live from HubSpot. Add a rep to that file, push, and they appear here.

Role-based access is not live yet, and this page does not pretend otherwise. Every device unlocks with a PIN that returns the same shared WORKSPACE_KEY, so the worker cannot tell Ricky from Tyler — there is no server-side identity to enforce against. Switching reps below changes what is displayed, not what is permitted: anyone with a PIN can view any rep's numbers. Making "a rep sees only their own" actually true requires Cloudflare Access in front of the domain so the worker receives a verified identity header. Until that exists, treat this as a convenience filter, not a permission boundary.
