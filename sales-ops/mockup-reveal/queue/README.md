# Mockup Reveal Queue

This cockpit is dedicated to prospects we've already built a free "ghost page"
homepage mockup for (live at `https://urbanbackstage.com/demo/<slug>/`, not
indexed publicly — proof-of-work shown during the call). Every record in
this queue always has a `mockup_url`. There is no mode/toggle to signal —
if a prospect is in this queue, the mockup pitch is the whole call.

**This is a curated fixed list, not a daily-generated dial queue** — unlike
cold-call's queue, prospects don't age out overnight (the mockup doesn't
expire), so this folder works differently from the rest of Sales OS:

- `latest.json` — **the standing batch.** The cockpit always finds this file
  regardless of what today's date is. This is the one to keep updated —
  whenever a new mockup gets built, add that prospect here (append to
  `prospects`, or replace the whole file with the current full batch).
  Nobody needs to remember to rename anything for this to keep working.
- `YYYY-MM-DD.json` (optional) — a same-day snapshot, kept only for
  historical reference. The cockpit checks today's dated file *first* (in
  case one exists) and falls back to `latest.json` automatically if it
  doesn't — so a dated file is a nice-to-have, never a requirement.

**Generated by:** `phone-qualifier` skill (Cowork command) — write straight
to `latest.json`.
**Read by:** the cockpit on load (today's dated file if present, else
`latest.json`, always).

## Schema

```json
{
  "_date": "2026-05-12",
  "_generated_at": "2026-05-12T09:00:00Z",
  "_session_cap": 15,
  "prospects": [
    {
      "contact_id": "hubspot_contact_id",
      "business_name": "Acme Roofing",
      "first_name": "Mike",
      "last_name": "Roberts",
      "trade": "Roofer",
      "phone": "+1 555-123-4567",
      "city": "Dubuque",
      "state": "IA",
      "hubspot_url": "https://app.hubspot.com/contacts/...",
      "last_touched": "2026-05-01",
      "last_outcome": null,
      "notes_preview": "Brother handles marketing per gatekeeper note",
      "pipeline_stage": "First Touch Sent",
      "mockup_url": "https://urbanbackstage.com/demo/il-example-co-ab12cd/",
      "ai_hook": "Single-sentence AI-generated hook specific to this prospect — populated by phone-qualifier skill at queue build time. Example: 'Already built Acme Roofing a free working homepage — lead with that, not a review-gap stat.'"
    }
  ]
}
```

`mockup_url` is required for every record in this queue — it's the reason the
prospect is here instead of in the regular cold-call queue. There is no
`pitch_mode` field (that concept doesn't apply — this cockpit only ever runs
the mockup pitch).

## Cool-down policy

Cockpit warns if `last_touched` is within 7 days unless `last_outcome` is `WARM`
with a pending callback. Override is per-call (one click "dial anyway").

## How phone-qualifier writes here

Cowork command at end of `phone-qualifier` skill output:

```
Step 7: Save the queue to GitHub
1. Format the prospects as JSON matching the schema above
2. Push to /sales-ops/mockup-reveal/queue/latest.json on main (replace the
   whole file with the current full standing batch — don't create a new
   dated file unless you specifically want a same-day historical snapshot)
```

If `latest.json` is ever missing or empty, cockpit falls back to manual-dial mode.

**When phone-qualifier finds a prospect that already has a mockup built**
(check the same way this batch was found — via `demo/index.html` on
urbanbackstage.com, or a future manifest of built mockups), route that
prospect into this queue file instead of the regular cold-call queue, with
`mockup_url` set to the live demo URL.

## ai_hook field

Each prospect in the queue can carry an `ai_hook` — a single sentence generated by Claude at queue build time, specific to that prospect's situation. The cockpit displays it on the prospect card before you dial. For this queue, the hook is simply that the mockup exists — no generic review-gap stat needed.

**Generated by:** phone-qualifier skill (Claude API call per prospect using their HubSpot data + GBP/review data)
**Format:** One sentence, specific and factual. 'Already built Acme Roofing a free working homepage — lead with that, not a review-gap stat.'
**If absent:** cockpit shows notes_preview instead. Never blocks the dial.
