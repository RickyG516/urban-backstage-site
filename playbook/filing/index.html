Naming & Filing Rules

Every file that leaves a session gets a name from this pattern and a filing stamp at the top. No exceptions — it's what keeps Drive from turning back into a junk drawer.

The Pattern

Standard   [Entity]_[DocType]_[Description]_[YYYY-MM-DD].[ext]
Versioned   [Entity]_[DocType]_[Description]_v[N]_[YYYY-MM-DD].[ext]

No spaces. Underscores between parts, hyphens within a part.

The Filing Stamp

Goes at the very top of every file, before any other content. No stamp, no filing.

FILING DESTINATION: [DEPARTMENT] / [Subfolder] / [Sub-subfolder if needed]

The Other Standing Rules

Rule 2Everything saves to C:\UrbanNicheCo\Staging\ first. Upload to Drive, delete local, machine stays clean. Bulk purges use Downloads\TO_UPLOAD\ and Downloads\TO_DELETE\ — OAuth / client_secret JSON goes to TO_DELETE only, never Drive.
Rule 3PDF for anything client-facing or archived. HTML for internal daily-use docs that live on backstage. Amended July 2026 — used to be PDF for everything a human reads.
Rule 4Pull or clone before editing. Audit first. Surgical changes only. Never break existing layout or styling.
Careful what lands on the open playbook. The test is simple — if a competitor read this, would it hurt? Account IDs, namespace IDs, tokens, security runbooks and competitive intel stay behind the cockpit PIN or in Drive only. Process, training, personas and brand are safe out here.
