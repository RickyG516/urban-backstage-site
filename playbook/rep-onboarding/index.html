Rep Onboarding

Run this every time a new rep joins. About 45–60 minutes of active work, plus async waiting on the rep to accept invites. Your progress saves in this browser.

Progress 0 / 11

Before You Start

Collect from the rep
Do this before touching any system
RICKY
  1. Full legal name
  2. Personal phone number
  3. Personal email — temporary, only until the UNC address exists
  4. Confirmation they've read and understood the comp plan
Heads up: the original SOP points reps at urbannicheco.com/careers/sales-rep, but the careers index no longer links that page — it was superseded by the separate Setter and Closer pages. Send them urbannicheco.com/careers/ and the page for their actual seat until that's reconciled.

Day One — Systems

1. Create the UNC email
Google Workspace Admin · ~5 min
RICKY
  1. Go to admin.google.com → Users → Add new user
  2. First name, last name, primary email [firstname]@urbannicheco.com
  3. Choose "Create password", generate one, screenshot it before clicking Create
  4. Confirm the account appears in the user list
  5. Send the rep their email + temp password via personal phone or email
Done when: rep has [firstname]@urbannicheco.com active.
2. HubSpot seat + invite
~4 min · run after step 1
RICKY
  1. Go to Users & Teams → Create user
  2. Enter [firstname]@urbannicheco.com → Next
  3. Permissions: Sales rep role / Core Seat → Send invite
  4. Open their name in the user list and copy the full URL from the address bar
  5. Pull the owner ID out of it — you need it for step 7
URL shape: .../users/user/[OWNER_ID]/access
Note: HubSpot Starter includes 2 Core Seats; extras run about $10.64/mo. Check billing first if you're unsure of the count.

~4 min
RICKY

  3. Share to [firstname]@urbannicheco.com as Contributor
  4. Uncheck "Notify people" → Share
Done when: folder exists and is shared. Every future client folder auto-creates inside it via drive-filing.

Async — rep does this themselves

Go Live

9. Onboarding call
30–45 min · once steps 1–8 are done
BOTH
  1. Walk the Sales OS cockpit; confirm their name is in the rep dropdown
  2. Walk the service knowledge guide, answer questions
  3. Run three mock cold calls together in the cockpit
  4. Role-play the top three objections off the objection card
  5. Show logging a call via call-logger, running website-audit before a discovery call, and output-the-chat at session end
  6. Set the week-one dial target and the daily text: dials / conversations / bookings
Hard gate: the commission agreement must be signed before they dial once.
10. Week-one check-in
Day 5 or 6 after their first dial session
BOTH
  1. Dial count against target
  2. Outcomes actually logged in HubSpot
  3. Any replies or warm leads to handle
  4. Questions on scripts, services, objections
  5. Fix whatever isn't working

When They Close Their First Client

Run client-lifecycle in Onboard mode — Ricky briefs it first. drive-filing auto-creates the client folder inside the rep's client folder; share it with them if they need visibility. Commission statement goes out by the 10th of the following month, and Claude Max gets reimbursed for any month they have an active client.
